نور تولز - مشروع تغليف أندرويد

مهم:
- ملف التطبيق الأصلي محفوظ داخل app/src/main/assets/index.html دون تعديل.
- هذا المشروع يغلّف ملف HTML داخل تطبيق Android يفتح محليًا دون الحاجة إلى تحميل الصفحة من الإنترنت.
- تمكين العمل دون إنترنت يعتمد على أن وظائف الملف لا تحتاج إلى خدمات خارجية. أي ميزة تعتمد على خادم أو رابط خارجي لن تعمل دون اتصال.

لإنشاء APK عبر GitHub Actions:
1) ارفع محتويات هذا المجلد إلى جذر مستودع GitHub جديد أو المستودع المطلوب.
2) افتح تبويب Actions ووافق على تفعيل GitHub Actions إذا طُلب منك.
3) افتح سير العمل Build Noor Tools APK وشغّله عبر Run workflow، أو انتظر اكتمال التشغيل التلقائي بعد الرفع.
4) افتح التشغيل الناجح، وانزل إلى Artifacts، ثم نزّل Noor-Tools-APK.zip.
5) فك الضغط لتحصل على app-debug.apk وثبّته على جهاز Android.
